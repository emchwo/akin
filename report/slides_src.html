How people get to know each other today

Small talk, a card deck, or a chatbot's list of questions. They're safe and generic, and none of them reaches how the other person actually sees love.

Why I built it

When I first came to Yale SOM, I made a lot of new friends through proximity, but I wanted to connect with them on a deeper level too. There's a similar feeling that arises when dating and getting to know someone for the first time. It's fun and illuminating to talk about how we see love and relationships, so I wanted to build something to facilitate that.

What's new

Not a question deck: a game that listens

Akin is powered by AI agents that analyze the players' responses and create an archetype at the end for people to identify with. Traditional conversation decks like We're Not Really Strangers, or conversation starters like the classic 36 Questions to Fall in Love, can't do the same.

Safety

{{safety_held_words}}, tested under attack

  • Prompt injection: names are filtered, and never sent to the model at all
  • Unsafe content: a code screen plus a Checker on every scenario
  • Invented facts: evidence must cite real rounds, checked in code
  • Loops and overspending: retry limits, an 8-round cap, 40 calls per game, token caps
  • Misclicks: back buttons, change an answer, undo a round

"Ignore all instructions" as a name is rejected. Every defense logs what it caught.

What changes at the table

Real sessionI played a full game with a friend in the Friends setting. It took about 20 minutes over 6 rounds, and the length of each conversation varied from round to round.
FeedbackHis main piece of feedback was that the ending page was too cut-and-dry: "the ending felt like it was just repeating our answers back to us."
What changedThe reveal now interprets what each person values and how their views shape the way they connect, citing the rounds behind it.
  • Structured, personal questions raise closeness between strangers (Aron et al., 1997)
  • Akin adds what a deck can't: adaptive topics, private answers, and an archetype with evidence

What's next

From a local server to a link anyone can open

  • Host it online: turn Akin into a link anyone can open, or a mobile app, so no one has to start a server before playing
  • Two-device mode: let each player answer on their own device, so answers stay truly private
  • Validate the types: compare them with an established relationship-beliefs questionnaire across more players
  • Friends-specific results: write types for "how you'd advise each other," not only how each person sees love
  • A post-date card: share your two types and the prompts that started the best conversations
  • Test cost against quality: A/B test the Checker and reasoning effort for quality per cent of cost
